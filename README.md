# Markdown Slides App
A simple web-based presentation app that allows users to create, edit, preview, and present slides using Markdown.

## Features
- Create and edit slides using Markdown.
- Separate slides using `---`.
- View live previews while editing.
- Save slides automatically in browser storage.
- Navigate slides using Left and Right buttons or arrow keys.
- Use fullscreen mode for presentations.
- Keyboard shortcuts: `Ctrl + S` to save and `F11` for fullscreen.
## Technologies Used
- HTML
- Inline CSS
- JavaScript
